# IntentOS 下載

## 請下載這一份

[下載 latest.zip（密碼 ZIP）](https://raw.githubusercontent.com/caseykcc0124/encrypted-transfer/main/latest.zip)

1. 下載上方的 `latest.zip`。
2. 用支援 AES 密碼 ZIP 的解壓縮軟體開啟，例如 7-Zip 或 WinRAR。
3. 貼上寄件者另行提供的 **Skill 固定密碼**，解壓即可。

解壓縮不需要執行任何 Python、腳本或終端機指令。部分系統內建解壓縮功能不支援 AES，請用支援的解壓縮軟體。

請使用上面的直接下載連結；GitHub Code → Download ZIP 下載的是儲存庫外層 ZIP，裡面仍需開啟密碼 ZIP。
