# IntentOS 下載

請直接下載 [IntentOS 密碼 ZIP](https://raw.githubusercontent.com/caseykcc0124/encrypted-transfer/main/IntentOS-20261010-password.zip)。

1. 下載 `IntentOS-20261010-password.zip`。
2. 用支援 AES 密碼 ZIP 的解壓縮軟體開啟，例如 7-Zip 或 WinRAR。
3. 輸入寄件者另外提供的密碼，解壓縮即可。解密不需要執行 Python、腳本或終端機指令。

部分系統內建的解壓縮功能不支援 AES 密碼 ZIP，請使用支援此格式的解壓縮軟體。

包內包含 `IntentOS/` 原始碼、前端網頁、測試與文件、可還原的 `IntentOS-history.bundle`、內容雜湊清單與說明。原始碼版本：`b1ed1a83c0158c3e449cd4406d89058b001569bf`。

ZIP SHA-256：`b8dc0c734de4fc1bb8df7ae9e6ccc0327f8fcb2e428776f88df7ad6dd417589f`。

這是專案版本包，未包含既有意圖對話、材料、任務成果或 Python／Orca 安裝程式。解壓縮不需腳本；執行 IntentOS 本身仍需其執行環境，請看包內 README。

`latest.zip.enc.txt` 是先前的自訂加密快照，保留作為歷史備份；一般收件者請使用上方的密碼 ZIP。密碼不放在此儲存庫。
